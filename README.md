# Wildbound v2

Mod RPG para **Minecraft · Fabric 26.3**.

- Sistema de niveles.
- HUD animada con la tecla **H**.
- Elementos con 10 habilidades cada uno.
- Habilidades cinematográficas en tercera persona, lanzadas con un cetro 3D.

Consulta [ROADMAP.md](ROADMAP.md) para el estado del desarrollo y las directrices de trabajo.
